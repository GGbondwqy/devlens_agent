# 研发值班手册（OnCall Handbook）

## CI 失败处理 SOP

1. 先用关键字过滤日志（ERROR / FAILED / AssertionError），确定失败用例；
2. 从堆栈中提取 源码文件:行号，阅读对应提交（git show）确认改动来源；
3. 判断是「代码缺陷」还是「测试自身脆弱」，必要时关联历史 Issue；
4. 修复后必须本地复跑失败用例再推送。

## 金额类告警处理约定

- 金额异常（负数 / 0 元 / 放大 N 倍）一律按 P1 处理；
- 优先排查折扣、汇率、单位换算三类计算点；
- 修复必须附带边界单测（0 / 100 / 负数 / None）。
