# 历史故障记录（知识库）

## 2025-09-12 满减券负金额（P0）

现象：使用满减券后订单金额为负数。
根因：满减计算未做 max(price - value, 0) 保护，叠加运费后出现负值。
修复：引入 max 保护 + 单测覆盖边界。
关键词：优惠券 金额 负数 满减

## 2025-11-03 汇率单位混用（P1）

现象：跨境订单金额放大 100 倍。
根因：「元」与「分」单位混用，金额字段无单位标注。
修复：金额字段统一为「分」，引入单位不变量校验。
关键词：金额 单位 混用 汇率 放大

## 2026-01-20 折扣叠加导致 0 元单（P1）

现象：叠加使用两张百分比券后出现 0 元订单。
根因：折扣函数被连续调用两次，幂等性缺失。
修复：折扣计算收敛到单点，禁止链式叠加。
关键词：折扣 叠加 0元 幂等

## 金额计算检查清单（OnCall 必读）

1. 单位：百分数 / 小数 / 分，是否与字段注释一致？
2. 边界：value=0、value=100、负数输入、None 券。
3. 防护：折后价是否可能出现负数或 0 元？
4. 测试：改动金额逻辑必须补充对应单测。
